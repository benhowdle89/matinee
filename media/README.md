# Promo assets

Generated from `assets/hero.svg` by recording one exact loop in Chrome and
converting with ffmpeg. Regenerate with the recipe in HANDOFF.md.

| File | Use |
|---|---|
| `matinee-hero.mp4` | Social posts. Preferred over the GIF almost everywhere: smaller, sharper, and platforms that convert GIFs to video will do a worse job than this already is. |
| `matinee-hero.gif` | Anywhere that genuinely needs a GIF. |

Both are one complete 6.41s cycle, so they loop without a visible seam.
